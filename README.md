# Our Love — Birthday Website ♡

## Files included
- `index.html` — grand birthday landing page and memories page
- `style.css` — responsive layout, glow effects, animations
- `script.js` — page navigation, sparkles, photo cards
- `memories.json` — customise the name, love letter, photos, dates, titles and captions
- `assets/photos/` — put your own photos here

## Customise it
1. Open `memories.json` in any text editor.
2. Change `partnerName` to your lover's name.
3. Write your own message in `loveLetter`.
4. Change each memory's `date`, `title`, and `caption`.
5. Put your photos in `assets/photos/`, named `memory-01.jpg` through `memory-06.jpg` to match the JSON. PNG works too if you update the filename in JSON.
6. To preview, use VS Code with the Live Server extension. A local server is needed because the page loads `memories.json`.
7. To share as a link, upload the folder to a static hosting service. Remember that anyone with access to a public link may see the photos.

The project includes placeholders, not your personal photos. Add your own photos before sharing.
